# side_experiments

Exploratory scripts and abandoned experiments around the main pipeline.

| Directory | Content |
|---|---|
| `explore_grandtour/` | notebook and helpers for browsing the dataset |
| `lateral_movement_commands/` | analysis of the command twist (how much lateral movement is present) |
| `dino_feature_space/` | frozen DINOv3 features per mission, tagged by OOD tier |
| `wvn_loss_network/` | WVN-style OOD loss on the traversability network |
| `wrizz_labeling/` | pairwise human traversability labeling tool |
| `wrizz_image/` | W-RIZZ image-space network trained on those labels |
| `forent/` | abandoned ForEnt dataset experiments |
